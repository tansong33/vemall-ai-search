# 实体标签规范 v1.1

本规范同时约束人工金标、LLM 银标、规则预标注和线上实体解释。标签的机器可读事实来源是
[`../configs/labels_v1.yaml`](../configs/labels_v1.yaml)；两者不一致时必须停止扩产并修正。

## 通用规则

- **只标原文中连续、原样出现的文本**，不改写、不翻译、不补全。
- **不允许重叠或嵌套**。一个字符最多属于一个实体。
- **边界不含空格、括号和标点**；保留原始大小写、全半角，offset 指向当前 canonical `text`。
- **不确定就不标**。错标会产生错误过滤，通常比漏标更危险。
- 每个标题最多标 **一个主 CATEGORY**。SEO 近义词串、用途词、配件词不重复标类目。
- 数字单位优先走确定性规则；不能因为含字母和数字就把规格标成 MODEL。
- 数据库 brand/class/attr 是候选，不是天然真值。只有标题中真实出现的连续文本才可能成为 span。
- 空实体样本合法，必须保留。`包邮`、`官方旗舰店`、`正品`、`满减`通常全部为 `O`。

发生冲突时先按来源裁决：可靠的结构化原样品牌/类目、确定性数字单位规则，优先于语义模型
的猜测；同来源标签冲突再使用 `labels_v1.yaml` 的 priority。自动产线还会强制
`CATEGORY <= 1`，人工标注不得绕过。

## 16 个启用标签

### BRAND — 品牌

制造商、商业品牌或子品牌。中英双写拆成两个实体，括号不包含。

- 正例：`捷科`（`JETECH`）、`公牛`插座、`3M`胶带。
- 反例：`国产`手机、华为`授权店`、红苹果水果中的“苹果”。
- 品牌与系列连写时拆开：`华为`/BRAND + `Mate60`/MODEL。
- 单字符品牌（如 `A`）不做自动弱标，必须由人工结合上下文确认。

### CATEGORY — 主品类

标题实际售卖的“是什么”，取最具体、完整的中心词；每标题最多一个。

- 正例：公牛`插座`、`保温杯`、兄弟 PT-E550W `标签机`。
- 固定复合类目整体标：`智能门锁`、`电视柜`，不要只标“门锁”或“柜”。
- `螺丝刀一字起子机修工具螺丝批改锥`只标最前面的主品类`螺丝刀`。
- 数据库归档类目不等于标题类目：标题是“标签机”而 L3 是“家庭护理”时，不得标“家庭护理”。
- “套装、工具、配件、适用于手机”等泛词或适配对象通常不另标 CATEGORY。

### MODEL — 型号/系列

厂商型号、系列编号或型号主体加营销后缀。

- 正例：`GN-B303`、`Mate60 Pro`、`MX Master 3S`、`GTH8-250`。
- `Pro/Max/Plus/Ultra/SE/Lite/Mini`只有跟随型号主体时才并入；单独出现不标。
- 反例：`3P`、`63A`、`24V`、`55W`、`125mm`、`3英寸`、`41码`、
  `S`、`XXXL`、`40马力`。这些是规格/尺码，不是型号。

### SPEC — 通用规格

无法归入容量、尺寸、重量或包装数量的量化规格。

- 正例：`220-240V`、`63A`、`3000W`、`50Hz`、`3P`、`5号`、`4K`、
  `2700K`、量程`0-100mg/L`。
- 范围、浓度和复合表达整体标，不得只截右端。
- 型号内部的数字不拆出：`GN-B303`整体属于 MODEL。

### CAPACITY — 容量

存储容量或容积。

- 正例：`256G`、`1TB`、`500ml`、`5L`、`12GB+512GB`。
- 组合容量整体标成一个实体。
- `大容量`不量化，通常不标 CAPACITY。

### SIZE — 尺寸/尺码

长度、宽高、口径、英寸数、鞋服尺码等物理尺寸。

- 正例：`8x250mm`、`105-127mm`、`10英寸`、`41码`、`14Gx2.0mm`。
- `加长`没有数值，不标 SIZE；可在语义明确时标 FUNCTION。

### WEIGHT — 重量

质量、净重或承重数值。

- 正例：`500g`、`1kg`、`5公斤`、`20斤`。
- `0-100mg/L`是浓度规格，不是 WEIGHT。
- 大写 `G/T`在存储语境通常属于 CAPACITY，小写 `g/t`按重量规则处理。

### PACKAGE_COMBINATION — 包装组合

商品数量、包装单位或组合数量。

- 正例：`2只`、`20粒装`中的`20粒`、`100根`、`100个`、`1000条`、`3盒`。
- 单独销售单位且没有数量（只写“单位：台”）通常不标。

### COLOR — 颜色

商品表面颜色和稳定的营销色名。

- 正例：`黑色`、`深空灰`、`香槟金`、`远峰蓝`。
- `白酒`中的“白”、仅描述外包装的“彩色包装”不标商品 COLOR。

### MATERIAL — 材质

制造商品主体的原材料。

- 正例：`不锈钢`、`铝合金`、`PVC`、`陶瓷`、`铬钒镍钢`。
- 零部件或商品名不等于材质：`锂电池`不能因为含“锂”就整体标 MATERIAL。
- 数据库 `attr_json` 中“颜色=型号”等错配不能直接转成材质/颜色标签。

### FLAVOR — 风味

味觉或嗅觉风味，回答“什么味/什么香型”。

- 正例：`葡萄味`、`薄荷味`、`果香`。
- 数量表达“6口味”中的`6口`不是 SPEC。

### APPEARANCE — 外观形态

商品客观的形状、轮廓或造型。

- 正例：`圆形`、`扇形`、`直角`、`流线型`。
- “漂亮、时尚”是主观评价，不标 APPEARANCE；必要时归 MODIFIER。

### SCENE — 使用场景

使用环境、地点或采购场景。

- 正例：`家用`、`户外`、`旅行`、`车载`、`办公`。
- `手机`、`电脑`、`平板`、`轮胎`是适配对象或商品名，不是场景。

### AUDIENCE — 适用人群

明确面向的使用者群体。

- 正例：`儿童`、`学生`、`孕妇`、`老人`、`男士`。
- 固定复合品类需按中心词判断；无法稳定拆分时标完整 CATEGORY，不强拆 AUDIENCE。

### FUNCTION — 功能/特性

商品的能力、作用、效果或客观性能特性。

- 正例：`无线`、`静音`、`防水`、`便携`、`可敲击`、`加厚`、`加固`、`耐磨`。
- `铜`、`铬`、`镍`是材料词；`钥匙`、`总氮`等名词本身不是功能。

### MODIFIER — 兜底修饰

不能归入以上客观标签的主观或抽象修饰，优先级最低。

- 可标：在业务确实需要保留时的`元气`、`清新`、`美观`。
- 不标：`代表`等无商品语义词，以及`官方`、`正品`、`包邮`、`满减`等交易宣传词。
- 能归 FUNCTION/COLOR/APPEARANCE 等客观标签时，禁止使用 MODIFIER。

## 质检与升级

- LLM 的 `relocate_miss_rate`只检查“是否改写原文”，不代表语义正确；CATEGORY、MODEL、
  SCENE 必须用人工 gold 计算分标签 precision/recall。
- 冻结 test 只能来自双标、仲裁后的 gold，任何 silver 不得进入。
- 拿不准的样本标记 `ambiguous`，由负责人统一裁决并把新反例写回本规范。
- 修改边界或标签定义必须升版本，并在训练 manifest 中记录规范版本。
