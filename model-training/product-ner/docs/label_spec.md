# 实体标签规范 v1

**判定顺序（冲突时从上到下）：BRAND > MODEL > CATEGORY > SPEC > COLOR**

## 通用规则
- **不允许重叠 / 嵌套**。v1 的下游是 ES 过滤器，一个字符只能属于一个字段。
  `华为手机` 必须切成 `华为/BRAND` + `手机/CATEGORY`，**不能**再整体标一个 PRODUCT。
- **不确定就不标**。标错比不标代价大得多：漏标只是召回损失，标错会把用户过滤到错误结果里。
- **边界不含空格和标点**。`公牛 插座` 中 CATEGORY 是 `插座`（3-5），不是 ` 插座`。
- **保留原始大小写和全半角**，offset 以用户输入的原串为准。模型侧的归一化是等长的，不影响 offset。
- 一条样本可以**没有任何实体**（如 `包邮`），这是合法且必须保留的负样本。

## v1 启用的 5 个标签

### BRAND — 品牌
> 商品的制造商/品牌名，能作为 ES `brand` 字段过滤的那个词。

| 正例 | 反例 |
|---|---|
| `公牛`插座 | `红苹果`水果 → `苹果`此处不是品牌，整体不标 BRAND |
| `3M`胶带 | 华为`授权店` → 店铺后缀不属于品牌 |
| `致仕`保温杯（词典里没有，仍然要标） | `国产`手机 → 产地不是品牌 |

**易混边界**：品牌 + 系列名连写时，只把品牌部分标 BRAND，系列归 MODEL：
`华为Mate60` → `华为/BRAND` + `Mate60/MODEL`。

### CATEGORY — 品类
> 商品是"什么东西"，对应 ES `category`。取**最具体的名词中心词**。

| 正例 | 反例 |
|---|---|
| 公牛`插座` | `插座式`充电器 → 中心词是 `充电器` |
| 小米`电视` | 电视`柜` → 这是 `电视柜`，整体标一个 CATEGORY |
| `保温杯` | `杯` 单字一般不单独标，除非全文只有它 |

**易混边界**：修饰词不进 CATEGORY。`智能门锁` 中 `智能` 是修饰，但 `智能门锁` 是行业固定品类词 → 整体标。判断标准：**它是不是 ES 里真实存在的类目名**。

### MODEL — 型号
> 厂商型号/系列编号，通常含数字与字母。

| 正例 | 反例 |
|---|---|
| 公牛`GN-B303` | `256G` → 这是容量，标 SPEC |
| 华为`Mate60 Pro` | `2026款` → 年份属于 SPEC/不标 |
| 罗技`MX Master 3S` | `Pro` 单独出现 → 不标 |

**易混边界**：`Pro/Max/Plus/Ultra` 属于型号的一部分，跟随主型号一起标；单独出现则不标。

### SPEC — 规格
> 容量、尺寸、功率、数量、分辨率等可量化参数。

| 正例 | 反例 |
|---|---|
| `256G` / `12GB+512GB`（组合容量标成**一个**实体） | `大容量` → 非量化，不标 |
| `65英寸` / `3米` / `3000W` / `5孔` | `加长` → 不标 |
| `4K` / `1080P` | `GN-B303` 里的数字 → 属于 MODEL |

### COLOR — 颜色
> 商品颜色，含营销色名。

| 正例 | 反例 |
|---|---|
| `黑色` / `深空灰` / `香槟金` | `彩色`包装 → 描述包装不描述商品 |
| `远峰蓝` | `白酒` 中的 `白` |

## v1 暂不启用（已定义，配置里可一键打开）
- **MATERIAL（材质）**：`不锈钢` `铝合金`。暂缓原因：当前 ES 没有对应过滤字段，标了也用不上；等前端加了材质筛选再开。
- **AUDIENCE（适用人群）**：`儿童` `男士`。暂缓原因同上，且与 CATEGORY 边界模糊（`儿童手表` 是一个品类还是人群+品类？）。

## 已废弃
- **PRODUCT（商品名）**：与 CATEGORY 在几乎每条查询上重叠，必然产生嵌套实体，而 v1 是扁平结构。
  它想表达的"完整商品名"可以由 BRAND + MODEL + CATEGORY 拼接得到，不需要单独一层。

## 未知内容如何处理
- 无法归入以上 5 类的词一律留空（`O`）：`官方旗舰店` `包邮` `正品` `满减`。
- 拿不准的样本在 Label Studio 里勾 `ambiguous`，由 leader 每周统一裁决并回写本文档。
- 本文档每次修改必须升版本号并记录在 `docs/CHANGELOG`，因为它决定了标注一致性。
